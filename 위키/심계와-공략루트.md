# 심계와 공략 루트

둘은 이름이 비슷하지만 **완전히 다른 값**이다. 여기서 한 번 갈라 두지 않으면 계속 헷갈린다.

|  | 심계 (마음에 둔 사람) | 공략 루트 |
|---|---|---|
| 정체 | **스탯** `lover`, 값 하나 | **플래그** `G110xx`, 인물마다 따로 |
| 정하는 것 | 「변심의 꿈」에서 내가 고른다 | 그 인물의 결정적 사건을 완주하면 켜진다 |
| 바꾸기 | 변심 10 을 쌓아 꿈을 다시 꾸면 바뀐다. 횟수 제한 없음 | 사건을 봐야 켜지고, 되돌릴 수 없다 |
| 읽는 곳 | 101개 스위치가 읽는다 | 항목 조건의 `[X 공략 중] == 1` |

**확인됨**: 루트를 켜는 다섯 스크립트는 `lover` 를 한 번도 읽지 않는다. 즉 심계를 누구로 두든 루트 플래그 판정에는 직접 영향이 없다.

**하지만 루트로 가는 길목이 심계를 본다.** 그래서 실질적으로는 묶여 있는 경우가 있다.

네 루트를 길목까지 전이적으로 훑은 결과, **심계를 요구하는 것은 소사매 루트 하나뿐**이다.

| 루트 | 요구 심계 | 근거 |
|---|---|---|
| **소사매** | **소사매** | 게이트 `Ch_5_5_1_001` 이 「공동 영전 - 소사매 참전」을 요구하고, 그 플래그를 세우는 `ch5_4_4` 가 [마음에 둔 사람] == 소사매 안에 있다 |
| 엽운상 | 제한 없음 | |
| 용상 | 제한 없음 | |
| 하후란 | 제한 없음 | |

청성행도 심계를 본다 — `ch2_4_9_2` 가 [마음에 둔 사람] == 엽운상 을 요구한다 (2년 8월).

「루트와 심계는 별개」는 플래그 수준에서만 맞는 말이다. 회차를 짤 때는 **길목의 심계 조건**까지 봐야 한다. 런 플래너는 `route_forks.json` 의 `routeLover` 로 이것을 반영한다.

## 심계 (lover)

### 값

**확인됨.** 게임이 확정할 때 띄우는 문구로 확인했다. 간체 옛 판(`lua_legacy/`)이 원문을 그대로 들고 있다.

| 값 | 원문 | 인물 |
|---|---|---|
| 0 | 唐默铃 | 소사매 |
| 1 | 瑞杏 | 서행 |
| 2 | 叶云裳 | 엽운상 |
| 3 | 虞小梅 | 우소매 |
| 4 | 上官萤 | 상관형 |
| 5 | 夏侯兰 | 하후란 |
| 6 | 郁竹 | 욱죽 |
| 7 | 魏菊 | 위국 |
| 8 | 龙湘 | 용상 |

한국어 문구도 있다: `Story/M_Lover_06 = 마음에 둔 사람이 욱죽으로 변했다`.

> 2026-09-05 이전에는 1·3·4·8 을 서로 바꿔 적고 있었다. 세이브의 `lover` 값을 사람 이름으로 옮기려다 잡았다.

### 변심의 꿈 — 시점 제한이 없다

**확인됨 (게임 데이터).** 미션 `S8500_01` 의 조건은 이것뿐이다.

```
[변심] >= 10  그리고  [플래그 서장(프롤로그) 플래그] == 0
```

그리고 이 미션은 `_dayCheck` 가 **False** 다. dayCheck 가 False 인 미션 30개는 시점 필드를 보지 않고 조건만 보는데, **29개는 조건문 안에 자기 시점 제한을 따로 들고 있고 이 미션만 그것마저 없다.** 즉 **언제든, 몇 번이든** 온다. [[게임파일과-세이브]]

(미션 데이터의 구간 1년 4월 상순~5월 중순은 보지 않는 값이다. 이것 때문에 한동안 「1년차 봄 한 번뿐」이라고 잘못 적고 있었다.)

꿈이 끝나면 변심이 0 으로 돌아가므로, 다시 쌓으면 또 온다.

**변심이 오르는 상황**: 새 여성 인물을 만났을 때 「예쁘다」류 칭찬 선택지, 「나 때문에 다투지 마」류 자아도취 선택지. 그 밖에 사형에게 색종이를 사서 접기, 폐사찰에서 용상과 남매 맺기, 외보에서 용상과 복음 듣기, 공동 유학 중 우소매와 달리기, 탈백문 입문 후 하후란과 수련 실패, 공동 계절시험 3승 후 하후란과 장보기, 강릉 포위전에서 남궁천을 위해 나서지 않기, 엽가 남매 입주 후 엽운상과 장보기.

### 색지 접기 — 변심을 원하는 때에 올리는 수단

**확인됨 (작성자가 플레이에서 발견, 대본 `room_001_break_option` 으로 대조, 2026-10-07).** 사사형에게 산 색지(잡물 7002)가 있으면 남제자방 자유행동의 쉬는 화면에 세 번째 항목이 뜬다(`Misc_7002` = 색지 1개 이상). 고르면 색지 하나를 쓰고 **변심 +2**. 사건이나 선택지를 기다리지 않고 올릴 수 있는, 지금까지 찾은 유일한 수단이다 — 색지를 쌓아 두면 꿈이 오는 때를 고를 수 있다.

- **마음에 둔 사람이 소사매일 때는 변심이 안 오른다.** 같은 항목이 심상 +70 으로 바뀐다(`Lover_Sister_001`). 색지는 똑같이 하나 쓴다.
- **사는 법 (작성자의 플레이 기억, 2026-10-07 — 대본 미대조).** 사사형이 당문에 있는 동안은 언제든 살 수 있고, 유학 중이나 다른 자리에서도 사사형을 만나면 살 수 있다. **한 번 살 때 다섯 장까지**다(작성자, 게임에서 확인 2026-10-07 — 처음 기억은 「제한 없음」이었다). 값은 하나에 50 정도.
- 사사형이 당문을 떠난 뒤에는 살 길이 없으니 **있는 동안 넉넉히 사 둔다.**
- **한 번 접을 때 행동력 하나.** 자유행동에서 장소를 고르면 무엇을 하든 행동력을 하나 쓴다(작성자, 2026-10-07).
- **게임에서 됐다 (작성자, 2026-10-07).** 변심 7 에서 세 번 접고 꿈이 왔다. 한 장에 +1 이면 딱 10 이라 작성자의 기억(+1)과 맞고, 대본의 +2 와는 안 맞는다 — 다만 꿈은 잠들 때 오므로 두 번째에 이미 넘었을 수도 있어 이것만으로는 못 가른다. **계획은 한 장에 +1 로 잡는다.**
- 못 본 것: 다섯 장 제한이 언제 풀리는지(순이 바뀌면인지).

### 색지로 갈아탈 때 치르는 값 — 엽운상

**확인됨 (대본 `S0209_01` · `S0209_01_07`, 2026-10-07. 작성자가 짚었다).** 엽 남매를 붙잡은 회차는 3년 5월 하순에 미션 `S0209_01` 이 「엽운상이 당문에 있음 == 1 그리고 엽운상 공략 중 == 0」을 본다. 뜨면 어느 가지로 가도 `S0209_01_07` 에 닿고, 거기서 조건 없이 엽운상 · 엽운주가 당문에서 빠지며 **「엽운상 사망」(`E14000`)이 선다.** 막는 길은 「엽운상 공략 중」뿐이고 그것은 3년 5월 상순에 마음에 둔 사람이 엽운상이어야 들어가는 루트의 끝에서만 선다. 그러니 그 전에 다른 사람으로 갈아타면 엽운상을 잃는다. 남매를 애초에 안 붙잡은 회차는 이 미션이 안 뜬다(떠났을 뿐 죽지 않는다).

### 꿈에서 고르는 세 마디

**확인됨** (`S8500_01_02`). 선택지는 **그 인물을 이미 아는 경우에만** 뜬다.

```
키가 크고 날씬해야지
   솔직하고 명랑해야지 → 아주 유능해야지                  상관형
                      → 다소 멍청해 보이네                용상
                      → 살짝 미친 것 같아 보이네           우소매
   정숙하면서도 우아해야지                                하후란
아담하고 귀여워야지
   활발하고 명랑해야지 → 가냘프고 연약해야지               엽운상
                      → 그 힘이 산을 뽑을 정도여야지        욱죽
   얌전하고 온순해야지 → 티 없이 맑은 마음을 가져야지        소사매
                      → 학식과 예법을 갖춘, 명문가의 규수    위국
                      → 그녀의 힘은 산을 뽑을 정도          욱죽
```

욱죽은 두 갈래 모두에서 나온다. 둘 다 「힘이 산을 뽑을 정도」 쪽이다.

꿈 첫머리의 **「비단 주머니를 연다」** 를 고르면 서행이 된다. 2회차 이상에서만 열린다.

### 꿈 말고도 심계가 바뀌는 곳

**확인됨 (전수).** `SetPlayer("lover", N)` 을 하는 스크립트는 9개뿐이고, 그중 넷은 꿈이 아니다.

| 스크립트 | 바뀌는 심계 | 무엇 |
|---|---|---|
| `ch0_meeting_option_02` | 서행 | 서장(프롤로그) |
| `talk_brother3_option_03` | **우소매** | 삼사형과의 대화. 상시 |
| `S9905_01` | 엽운상 | 남제자방 밤 대화. 3년 12월 상순~4년 1월 중순, 난수 0~30 이 10 이하 |
| `ch3_8_4` | 하후란 | |
| `ch8_3_2_1_3` | 엽운상 | |

**이들도 변심을 0 으로 되돌린다.** 그래서 변심을 10 까지 쌓아 꿈을 노리는 중이라면 이 선택지들을 피해야 한다.

### 심계가 못박는 갈래

**확인됨.** 그 사람을 알아야 선택지가 뜨므로, 만나는 곳이 한 갈래뿐인 인물은 심계만으로 회차가 정해진다.

| 심계 | 함의 | 근거 |
|---|---|---|
| 하후란 | 공동파 + 탈백문 | `G10005` 는 `S0014_01_03/_06` 에서만 세워지고 입문 조건이 탈백문 |
| 우소매 | 공동파 | `G10004` 는 `ch2_5_3_2` 에서만 |
| 욱죽 | 공동파 + 철권문 | `G10006` 은 `section_01_free_03_01_02` 에서만, 그 갈래 조건이 철권문 |

**단, 2회차 이상에서는 함의가 없을 수 있다 (2026-10-03).** 「앎」 플래그(G100xx)는 회차를 넘어 남는다 — 철권문에 가지 않은 NG+ 탈백문 회차 세이브에 `G10001`~`G10007` 이 전부 1 이었고, 그 회차에서 심계가 욱죽이 됐다. 이미 아는 인물은 꿈에서 고를 수 있으므로 위 표는 「그 인물을 아직 모를 때」만 맞다. 리더는 세이브에 앎 플래그가 서 있으면 갈래를 묶지 않는다.

**욱죽은 이 빌드에서 거둘 수 없다 (2026-10-03, 확인됨).** 영입(`E13004`)은 `ch6_8_2_break_start_01` 의 「소매」 항목 하나에서만 서고 `[화중선과 결투](M60021) == 1` 로 잠겨 있다. M60021 은 금향궁 「화중선에게 도전하기」(`ch6_4_3_4_2`)에서만 서는데 그 항목은 `[M60019] == 1` 로 잠기고, M60019 는 `ch6_4_3_1` 의 `[M40048](공동 지하감옥에서 우소매 구함)` 가지에서만 선다. M40048 을 세우는 곳이 `lua` · `lua_legacy` · 미션 데이터 어디에도 없다. 마음에 두는 것(심계 욱죽)과 한#9 · #10 은 영입 없이 된다.

상관형·엽운상·용상은 당문에서 만나므로 함의가 없다. 위국은 공동파 말고 여행(`travel_result_601_903`)에서도 만날 수 있어 못 박지 않는다.

### 엽운상 루트의 실제 진입로

**확인됨.** 미션 데이터만 보면 2년차처럼 보이지만, 실제로는 **3년차 5장**이다.

```
ch5_4_1
   [엽운상이 당문에 있음] == 1 그리고 [엽운상 사망] == 0
   그 안에서 [엽운상 호감도] >= 50  →  M50024(엽운상 인연 전제조건) = 1
   → S0208_01 → ... → S0208_05_05 → 엽운상 공략 중 = 1
```

이 진입로는 미션 조건을 다시 검사하지 않으므로 「주인공이 당문에 없음」 같은 건 상관없다. ~~공동파 유학과 시기가 겹치지 않아 모순이 아니다.~~ → **틀렸다 (2026-09-30 · 10-02).** 시기는 안 겹치지만 엽운상이 그때까지 당문에 남지 않는다.

### 누가 3년 5월까지 남는가

**확인됨.** 진입로의 첫 조건이 「엽운상이 당문에 있음」인데, 그 전에 3년 1월 상순 `S0204_01`(特定, 조건: 엽운주가 당문에 있음)이 남매를 내보낸다. 붙잡는 가지는 `S0204_01_04_break_start_01` 의 `M20008_01` = 「유학 선택 == 1」 하나뿐이고, 그 값을 세우는 곳은 청성행(`ch3_3_1_1`)뿐이다.

| 회차 | 3년 1월 | 근거 |
|---|---|---|
| 공동파 유학 | 반드시 떠난다 | 작성자의 세이브(공동파): `StorySave` 에 `S0204_01` → `_03` → `_03_01` → `_01_01` 이 남아 있고 그 뒤로 E12000 · E12100 이 0 |
| 잔류 + 청성행 | 남을 수 있다 | 주사위(엽운상 호감도 + 난수 50 >= 80)와 선택지를 넘기면 `S0204_01_04_01` |
| 잔류 + 청성행 없음 | **반드시 떠난다** | 아래 |


그 뒤 3년 1월까지 E12100 을 0 으로 쓰는 자리는 청성 라인(`ch3_1_7_6_break_start_01`)뿐이다. 그래서 청성행을 안 탄 잔류 회차는 엽운주가 돌아와 있고, `S0204_01` 이 그대로 뜬다. **반증**: 청성행 없이 3년 2월에 엽운상이 당문에 있는 세이브가 나오면 틀린 것이다(잔류 세이브가 없어 플레이로는 확인하지 못했다).

도구에서는 엽운상 루트 경로에 `qc = '1'`(청성행)을 싣는다.
